## BookOS

A free, open-source Linux distribution based on **Fedora 44**, with its own Wayland desktop and support for **Samsung Galaxy Book** laptops.

[bookos.es](https://bookos.es/en/) · [Download](https://bookos.es/en/downloads) · [Docs](https://bookos.es/en/docs) · [About BookOS](https://github.com/bookos-os/bookos)

### Desktop

- [bookos-desktop](https://github.com/Evelynx08/bookos-desktop): Wayland compositor with the desktop (panel, dock, Launchpad, lock screen, gestures) drawn inside it, written in Rust

### Apps

- [BookOS-Settings](https://github.com/Evelynx08/BookOS-Settings): system settings
- [bookos-store](https://github.com/Evelynx08/bookos-store): app store
- [bookos-browser](https://github.com/Evelynx08/bookos-browser): web browser
- [bookos-shell](https://github.com/Evelynx08/bookos-shell): terminal
- [bookos-notepad](https://github.com/Evelynx08/bookos-notepad): notes
- [bookos-calc](https://github.com/Evelynx08/bookos-calc): calculator
- [bookos-clock](https://github.com/Evelynx08/bookos-clock): clock
- [BookOS-Player](https://github.com/Evelynx08/BookOS-Player): music player
- [BookOS-VoiceRecorder](https://github.com/Evelynx08/BookOS-VoiceRecorder): voice recorder
- [system-monitor](https://github.com/Evelynx08/system-monitor): system monitor
- [lumina](https://github.com/Evelynx08/lumina): WhatsApp Web as a native app
- [remap](https://github.com/Evelynx08/remap): keyboard remapping
